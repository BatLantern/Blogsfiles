#### 01 删除最小元素

**题目：** 在顺序表中删除最小元素,并返回被删元素值。删除的值由最后一个填补，顺序表为空报错并停止运行。无时间空间要求。

**代码(数组)：** [ **arr** 为已给数组，**counts** 由 `sizeof(arr01_01) / sizeof(int)` 计算得来]

```c++
void deleteMin(int arr[], int counts){
    //顺序表为空报错
    if (counts == 0){
        cout << "顺序表为空！";
        return;
    }
    // 手动寻找最小值
    int key = 0;
    int min = INT_MAX;
    for (int i = 0; i < counts; i++){
        if (arr[i] < min){
            min = arr[i];
            key = i;
        }
    }
    // 交换并覆盖删除值
    arr[key] = arr[counts - 1];
    cout << min;
}
```

**解释和补充：** **('&'的用法详见笔记#4)**
* 如果题目是让删除位置后的所有元素前移，一般最后一个数字是无意义的，无需特别处理。
* 这道题只需返回被删元素的值即可，只有一个返回值。如果是要求返回一整个修改好的数组，则需要使用'&'引用传参原地修改数组。

**标准答案(顺序表)：**

```c++
bool Del_Min(SqList &L, ElemType &value){
//删除L中最小元素节点，通过已绑定的引用参数value返回值
//删除成功，返回真；否则返回假。
    if(L.length == 0){
        //表空，终止操作并返回
        return false;
    }
    //假定0号元素值最小
    value = L.data[0];
    int pos = 0;
    //寻找最小值,并让value存储当前具有最小值的元素
    for(int i = 1; i < L.length; i++){
        if(L.data[i] < value){
            value = L.data[i];
            pos = i;
        }
    }
    //空出的位置由最后一个填补
    L.data[pos] = L.data[L.length - 1];
    L.length--;
    return true;
}
```


#### 02 逆置数组元素

**题目：** 逆置所有数组元素。无时间要求，要求常数级别时间复杂度[ $O\left ( 1 \right )$ ]。

**代码(数组)：** [ **arr** 为已给数组，**counts** 由 `sizeof(arr01_01) / sizeof(int)` 计算得来]

```c++
void swapNums(int arr[], int counts){
    // 用位运算交换首尾元素
    for (int i = 0; i < counts / 2; i++){
        arr[i] ^= arr[counts - i - 1];
        arr[counts - i - 1] ^= arr[i];
        arr[i] ^= arr[counts - i - 1];
    }
}
```

**解释和补充：** 
* 空间复杂度要求为常数级别说明不能使用额外变量和结构，只能原地修改。
* 把元素从中间分开，将对应的头尾元素交换即可。使用位运算还可以大大减少所需时间。

**标准答案(顺序表)：**

```c++
void Reverse(SqList &L){
    //辅助变量
    ElemType temp;
    for(int i = 0; i < L.length / 2; i++){
        //交换前半部分和后半部分(比如1234，交换14和23，就会变成4321)
        temp = L.data[i];
        L.data[i] = L.data[L.length - i - 1];
        L.data[L.length - i - 1] = temp;
    }
}
```

#### 03 删除指定元素

**题目：** 删除数组所有指定数值的元素。要求线性时间复杂度[ $O\left ( n \right )$ ]，常数级别空间复杂度[ $O\left ( 1 \right )$ ]。

**代码(数组)：** [ **arr** 为已给数组，**counts** 由 `sizeof(arr01_01) / sizeof(int)` 计算得来，x为所给需要删除的元素]

```c++
void deleteNums(int (&arr)[], int counts, int x)
{
    int prev = 0;
    for(int i = 0; i < counts; i++){
        //如果此位上的数字不是x，就移动到prev位上
        if(arr[i] != x){
            arr[prev] = arr[i];
            prev++;
        }
    } 
}
```

**解释和补充：** 
* 关于(&arr)[]和&arr[],后者会报错而前者不会的问题，是因为arr是个整体,如果分开分别引用里面的所有元素,会引发内存和安全性问题.
